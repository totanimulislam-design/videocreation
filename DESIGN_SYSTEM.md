# DESIGN_SYSTEM.md
# Professional Graphic Design Intelligence & Creative Standards

> **A Creative Rulebook for AI-Powered Professional Graphic Design**
>
> Design with intention. Compose with intelligence. Execute with precision.

---

# 1. PURPOSE OF THIS DOCUMENT

This document defines the mandatory visual, artistic, typographic, compositional, and creative standards for every graphic design generated by this platform.

The Runtime AI Designer must use this document as its primary creative design guideline.

The objective is to produce professional-quality graphic designs comparable to the work of experienced graphic designers, creative directors, advertising agencies, editorial designers, and visual communication specialists.

This is NOT a template styling guide.

This is a comprehensive creative design system.

Every design must demonstrate:

- Professional artistic direction.
- Intentional visual composition.
- Strong typographic hierarchy.
- Sophisticated color relationships.
- Excellent spacing and alignment.
- Meaningful use of visual elements.
- Appropriate visual storytelling.
- Consistent design language.
- Technical precision.
- Production-ready quality.

## Fundamental Rule

**Never generate a design merely by arranging text, images, and decorative shapes. Build a complete visual composition with a clear artistic purpose.**

---

# 2. THE CREATIVE DESIGN MINDSET

The Runtime AI Designer must reason about communication before proposing visual elements. Follow the one canonical sequence defined in `DESIGN_ENGINE_SPEC.md` §21:

**Brief Analysis → Communication Objective → Creative Direction → Composition Strategy → Visual Hierarchy → Typography → Color → Asset Selection → Construction → Rendering → Quality Evaluation → Revision.**

At brief analysis, extract the content, audience, language/direction, output medium and constraints; keep user facts exact and mark assumptions. At the objective stage, state the one message/action the design must communicate. Each later choice must support that objective. The Design Engine validates and constructs the plan; the Renderer produces evidence; the Quality Engine evaluates it; revisions return through construction and rendering. Never skip planning or claim a render alone proves quality.

## Design Intent

Every element must have a reason to exist.

Before adding an element, ask:

- What purpose does this element serve?
- Does it strengthen the visual message?
- Does it improve the composition?
- Does it support the visual hierarchy?
- Is it visually consistent with the creative direction?

If an element does not contribute meaningfully, remove it.

# 3. PROFESSIONAL DESIGN PRINCIPLES

The rules below turn the foundational and applied design principles into actionable decisions. Use them together, not as independent visual effects. The subsequent sections add nuance and examples; if a local heuristic conflicts with the communication objective or required content, preserve the objective and content.

| Principle | Meaning | Use when | Implementation approach | Common mistakes | Validation criteria |
|---|---|---|---|---|---|
| Visual hierarchy | A deliberate order of attention and information importance. | Every design; especially when content competes or must be read quickly. | Assign primary/secondary/tertiary/utility roles from brief importance; distinguish through a limited set of scale, weight, contrast, position, and isolation cues. | Making every item prominent; letting decoration outrank essential content; assuming size alone creates hierarchy. | At intended viewing size, a reviewer can identify the main message first and follow the intended reading order; all mandatory details remain findable and legible. |
| Balance | Distribution of perceived visual weight, not necessarily symmetry. | When a dominant image, headline, or cluster makes the canvas feel unstable. | Compare size, darkness, contrast, density, and position across the canvas; counterweight with space, scale, or a meaningful element, not filler. | Forcing symmetry; mistaking equal object counts for balance; filling empty space reflexively. | No unintended area overwhelms the focal point; intentional asymmetry still feels composed at a glance and at thumbnail scale. |
| Contrast | Difference that clarifies priority, separation, or meaning. | To distinguish hierarchy, improve legibility, or create a purposeful focal point. | Select a small number of contrast dimensions (scale, weight, tone, hue, shape, density); check text/background contrast for the actual medium. | Weak contrast for essential text; applying every contrast dimension everywhere; decorative contrast competing with message. | Essential text is readable at delivery size and required contrast checks pass; the focal point is distinct without unrelated elements shouting. |
| Alignment | Visible relationships that give elements structure and intentional placement. | Whenever multiple objects or text blocks form a group, column, edge, or baseline. | Choose a grid/edge/baseline or explicitly justified optical alignment; use shared anchors and consistent offsets. | Near-alignments, arbitrary coordinates, mixing alignments without intent, or forcing every object onto one grid. | Related edges and baselines align to the selected system within its stated tolerance; any deviations are visibly intentional, not accidental. |
| Proximity | Spatial grouping communicates which information belongs together. | When content has semantic groups such as event details, contacts, or CTA. | Keep related items closer to each other than to unrelated groups; use whitespace before adding boxes or rules. | Equal gaps between unrelated groups; cramped labels/details; borders used to compensate for unclear grouping. | A reviewer can infer intended groups without reading every word; no unrelated items appear fused. |
| Repetition | Recurring visual features build coherence and recognition. | Across one design, a brand system, or a multi-page/carousel sequence. | Reuse selected tokens, type roles, spacing units, shapes, or motifs; vary only when hierarchy or content requires it. | Repeating everything mechanically; inconsistency in repeated tokens; creating monotonous or template-like output. | Repeated features are consistent and purposeful; differences are explained by content or hierarchy; the design still has a clear focal point. |
| Negative space | Unoccupied area is an active part of composition that separates and emphasizes. | Around focal content, between groups, or where density impairs comprehension. | Reserve breathing room according to hierarchy; assess the silhouette and relationship of empty zones as well as objects. | Filling every gap with decoration; confusing empty space with wasted space; isolating content so much that relationships break. | Text and groups remain legible and distinct; empty areas support focus, flow, and balance rather than reading as accidental holes. |
| Visual rhythm | Repeated or changing visual cues guide attention through a sequence. | When a design needs directional flow, progression, or continuity across panels/pages. | Use controlled repetition, alternation, scale, spacing, alignment, or directional forms consistent with the reading direction. | Unmotivated zig-zags, too many competing paths, or rhythm that conflicts with reading order. | A reviewer can trace the intended path in order; the route reaches the required information and CTA without dead ends or distracting loops. |
| Composition and focal point | The organized whole and its dominant attention anchor. | Every canvas; especially when a product, portrait, headline, or offer must lead. | Choose a suitable structure/pattern, establish zones and focal strategy, then adapt to actual content and aspect ratio. | Treating rule-of-thirds/golden ratio as mandatory; using multiple competing focal points; copying pattern coordinates. | One primary entry point and coherent reading flow are apparent at thumbnail and intended size; no required content is sacrificed. |
| Typography | Letterforms, hierarchy, spacing and shaping used as both information and visual form. | Every design containing text; script support is essential in multilingual work. | Select script-capable roles, measure shaped text before final placement, tune line breaks/leading/tracking, and keep editable text when possible. | Unavailable glyphs, too many typefaces, text squeezed into space, decorative treatment reducing legibility, incorrect direction. | No missing glyphs or clipping; essential copy is readable at output size and direction/line breaks are checked in actual render. |
| Color | A role-based system that communicates tone, grouping and contrast. | To support brand, mood, hierarchy, accessibility and medium-specific reproduction. | Assign background, text, surface, accent and semantic roles; check contrast and test the palette in the actual medium. | Unrelated colors, decorative gradients without purpose, low-contrast essential text, assuming screen color proves print fidelity. | Palette supports the objective; applicable digital contrast checks pass; print-dependent color is reviewed against a defined profile/proof. |
| Asset selection | Imagery/illustration that supplies meaning, evidence, emotion or focal emphasis. | When the brief benefits from a subject, product, environment or visual metaphor. | Select based on objective, audience, crop/aspect ratio, resolution, cultural context and permitted usage; define a fallback before construction. | Generic stock imagery, conflicting illustration styles, unverifiable rights, weak crop, treating an image as a replacement for editable design. | Asset relevance and crop are inspected in context; source/rights and availability are recorded; output resolution and focus remain appropriate. |

For every major design decision, record its purpose in the plan (for example, the target hierarchy role, alignment anchor, or reading-order relation). These are creative review criteria, not claims that every aesthetic property has a deterministic numerical test. Objective checks and human/AI visual evidence are distinguished in `DESIGN_QUALITY_METRICS.md`.

## 3.1 Visual Hierarchy

Visual hierarchy determines the order in which viewers perceive information.

Establish clear levels of importance.

### Hierarchy Levels

**Primary Level**
- Main headline.
- Main visual.
- Central message.
- Most important information.

**Secondary Level**
- Supporting headline.
- Important details.
- Secondary visual elements.

**Tertiary Level**
- Additional information.
- Descriptions.
- Captions.
- Supporting labels.

**Utility Level**
- Contact information.
- Website.
- Address.
- Social media information.
- Legal information.

**Decorative Level**
- Background patterns.
- Abstract shapes.
- Small visual accents.
- Ornamentation.

### Hierarchy Techniques

Use a combination of:

- Size contrast.
- Weight contrast.
- Color contrast.
- Positional importance.
- Spatial isolation.
- Typographic distinction.
- Shape differentiation.
- Negative space.

Never make every element equally prominent.

The viewer should understand the most important message almost immediately.

## 3.2 Balance

Balance the visual weight of all elements.

Support:

- Symmetrical balance.
- Asymmetrical balance.
- Radial balance.
- Crystallographic balance.
- Dynamic balance.

Do not assume that every design must be symmetrical.

Asymmetrical compositions can be highly sophisticated when visual weight is properly controlled.

## 3.3 Contrast

Use contrast to create distinction and visual interest.

Support:

- Light versus dark.
- Large versus small.
- Bold versus regular.
- Warm versus cool.
- Solid versus outline.
- Geometric versus organic.
- Dense versus spacious.
- Sharp versus soft.

Avoid insufficient contrast between text and background.

## 3.4 Alignment

Every element should have an intentional alignment relationship.

Use:

- Left alignment.
- Right alignment.
- Center alignment.
- Edge alignment.
- Optical alignment.
- Baseline alignment.
- Grid alignment.

Do not position objects arbitrarily.

## 3.5 Proximity

Related information should be visually grouped.

Keep unrelated information visually separated.

Use spacing and grouping to communicate relationships without requiring unnecessary borders or boxes.

## 3.6 Repetition

Repeat visual elements intentionally to create consistency.

Examples:

- Repeated accent colors.
- Consistent corner treatments.
- Repeated typography styles.
- Recurring shapes.
- Consistent spacing.
- Repeated decorative patterns.

Avoid excessive repetition that makes the design monotonous.

## 3.7 Negative Space

Negative space is an active design element.

It creates:

- Focus.
- Clarity.
- Elegance.
- Visual breathing room.
- Separation.
- Sophistication.

Do not fill every empty area with decorative elements.

A professional design often becomes stronger when unnecessary objects are removed.

## 3.8 Visual Rhythm

Create a visual flow that guides the viewer through the composition.

Use:

- Repetition.
- Alternation.
- Scale changes.
- Directional movement.
- Spacing variations.
- Pattern relationships.
- Typographic progression.

The eye should move naturally through the design.

# 4. ART DIRECTION AND CREATIVE STYLES

The Runtime AI Designer must understand different visual languages and apply them intentionally.

A style is not simply a color palette or a collection of decorative effects.

It is a complete visual language involving typography, composition, shapes, textures, imagery, spacing, and artistic personality. For any selected direction, the Runtime AI Designer must articulate its **meaning** (the traits that define it), **appropriate use** (objective/audience/brand fit), **implementation** (consistent choices across composition, typography, color, shape and assets), **common mistakes** (cliché, incoherent mixing, or over-styling), and **validation** (inspect whether the rendered choices form one coherent language and preserve readability). Each entry's `Characteristics` and `Use for` notes are starting evidence, not a license to apply a style mechanically.

# 5. PROFESSIONAL COMPOSITION SYSTEM

Composition is the foundation of visual quality.

The Runtime AI Designer must choose a composition strategy before placing elements.

## 5.1 Composition Types

### Central Composition
A central focal point surrounded by supporting elements.

### Asymmetric Composition
Unequal distribution of visual elements with controlled visual balance.

### Split Composition
Two or more distinct visual zones.

### Diagonal Composition
Directional movement through diagonal elements.

### Radial Composition
Elements arranged around a central point.

### Modular Composition
Content organized into structured modules.

### Editorial Composition
Magazine-inspired information and image hierarchy.

### Layered Composition
Overlapping elements that create depth.

### Typography-Led Composition
Typography serves as the primary visual element.

### Image-Led Composition
A dominant image establishes the visual identity.

### Freeform Composition
An expressive composition without a rigid visible grid.

### Frame-Based Composition
Content is organized through framing elements.

## 5.2 Grid Systems

Support:

- 2-column grids.
- 3-column grids.
- 4-column grids.
- 6-column grids.
- 8-column grids.
- 12-column grids.
- Modular grids.
- Baseline grids.
- Asymmetric grids.
- Freeform grid systems.

The grid must adapt to the document dimensions and content.

Do not force every design into a 12-column layout.

## 5.3 Golden Ratio and Proportional Systems

Use proportional relationships as optional creative tools.

The golden ratio can help establish:

- Element proportions.
- Image relationships.
- Headline scale.
- Spatial divisions.
- Composition balance.

Never treat mathematical ratios as mandatory rules.

Optical balance and communication clarity take priority over mathematical perfection.

## 5.4 Focal Point Management

Every design should have a clearly identifiable focal point.

Possible focal points:

- Main headline.
- Hero image.
- Product photograph.
- Illustration.
- Large number.
- Central geometric composition.
- Important announcement.

Do not create competing focal points unless the concept specifically requires them.

# 6. TYPOGRAPHY DESIGN SYSTEM

Typography is not merely the presentation of text.

It is a major visual component of the composition.

The Runtime AI Designer must treat typography as both communication and graphic form.

## 6.1 Typographic Roles

Define:

- Display headline.
- Primary headline.
- Secondary headline.
- Subheading.
- Body text.
- Caption.
- Label.
- Metadata.
- Call-to-action.
- Decorative text.

## 6.2 Typeface Classification

Understand the characteristics of:

- Neo-grotesque sans-serif.
- Geometric sans-serif.
- Humanist sans-serif.
- Old-style serif.
- Transitional serif.
- Modern serif.
- Slab serif.
- Display typefaces.
- Condensed typefaces.
- Monospaced typefaces.
- Script typefaces.
- Decorative typefaces.

## 6.3 Typography Pairing

Use compatible typeface combinations.

Examples:

| Combination | Visual Personality |
|---|---|
| Inter + Playfair Display | Modern editorial |
| Manrope + Merriweather | Professional editorial |
| Montserrat + Lato | Contemporary promotional |
| DM Sans + DM Serif Display | Modern premium |
| Space Grotesk + Inter | Experimental modern |
| Noto Sans Bengali + Noto Serif Bengali | Bengali editorial |
| Hind Siliguri + Inter | Modern educational |
| Noto Sans Arabic + Cairo | Contemporary Arabic |

These are starting points, not fixed prescriptions.

## 6.4 Typography Rules

- Prefer a controlled number of font families.
- Establish clear size relationships.
- Avoid excessive font-weight variations.
- Use appropriate line lengths.
- Maintain readable line spacing.
- Consider optical kerning.
- Avoid accidental text collisions.
- Use deliberate line breaks.
- Preserve appropriate letter spacing.
- Use text wrapping intelligently.

## 6.5 Multilingual Typography

Support:

- English.
- Bengali.
- Arabic.
- Urdu.

Requirements:

- Correct Unicode rendering.
- Proper Bengali conjunct shaping.
- Proper Arabic glyph shaping.
- Right-to-left direction.
- Appropriate punctuation handling.
- Language-aware font fallback.
- Accurate text measurement.
- Correct export rendering.

Never split complex-script grapheme clusters incorrectly.

## 6.6 Expressive Typography

Allow typography to become part of the visual artwork through:

- Oversized headlines.
- Cropped typography.
- Text masks.
- Text on paths.
- Curved text.
- Rotated text.
- Vertical text.
- Outline typography.
- Layered typography.
- Variable font axes.
- Custom letter spacing.
- Typographic patterns.

Use these techniques when they strengthen the concept.

# 13. SPACING, PROPORTIONS AND ALIGNMENT

Use a consistent spacing system.

Spacing should be proportional to the canvas dimensions and content hierarchy.

Define reusable spacing tokens.

```json
{
  "spacingScale": {
    "xs": 4,
    "sm": 8,
    "md": 16,
    "lg": 24,
    "xl": 32,
    "2xl": 48,
    "3xl": 64
  }
}
```

These values are illustrative starting points.

Use optical correction where mathematical alignment looks visually incorrect.

Maintain:

- Consistent margins.
- Logical grouping.
- Appropriate paragraph spacing.
- Balanced padding.
- Consistent alignment.
- Clear separation between sections.

# 14. DESIGN ADAPTABILITY

The design must adapt intelligently to different output dimensions.

Never stretch a composition blindly.

When converting a design:

1. Re-evaluate the visual hierarchy.
2. Recalculate element proportions.
3. Adjust grid structure.
4. Reposition images.
5. Recalculate typography sizes.
6. Adjust spacing.
7. Reconsider decorative elements.
8. Recheck visual balance.

Support:

- Portrait.
- Landscape.
- Square.
- Wide banner.
- Tall social media.
- Multi-page layouts.
- Custom print dimensions.

The adapted composition should look intentionally designed for its new format.

# 16. VISUAL CRITIQUE AND REFINEMENT

The Runtime AI Designer must inspect the rendered design, not just its source code.

A structurally valid design may still be visually weak.

Use the following critique process:

### Critique Questions

1. Does the design immediately communicate its purpose?
2. Does it have a distinctive creative identity?
3. Is the headline visually compelling?
4. Is the composition sophisticated?
5. Does the typography feel professionally selected?
6. Are the colors harmonious?
7. Is the visual balance convincing?
8. Is the use of negative space appropriate?
9. Are the decorative elements meaningful?
10. Does the design feel generic or repetitive?
11. Does it resemble a professional finished artwork?
12. What specific improvements would make it stronger?

### Refinement Rules

- Correct the most important weakness first.
- Preserve successful design decisions.
- Avoid unnecessary complete redesigns.
- Make targeted changes.
- Re-render after corrections.
- Re-evaluate the result.

Do not claim that a design is professionally finished without inspecting its rendered appearance.

# 17. STRICT DESIGN ANTI-PATTERNS

The Runtime AI Designer must actively avoid the following mistakes.

## Avoid Generic Template Design

Do not repeatedly use:

- Headline at the top.
- Image in the center.
- Three identical cards at the bottom.
- Generic gradient backgrounds.
- Random floating circles.
- Repeated rounded rectangles.
- Unnecessary decorative lines.

These patterns may be appropriate in individual designs, but must never become the default composition for every request.

## Avoid Poor Typography

Never:

- Use too many unrelated fonts.
- Use tiny text for important information.
- Stretch text unnaturally.
- Ignore line spacing.
- Allow text clipping.
- Use unreadable contrast.
- Randomly rotate important text.
- Apply decorative effects to every headline.

## Avoid Poor Color Usage

Never:

- Use too many unrelated colors.
- Apply gradients without purpose.
- Use low-contrast text.
- Mix incompatible color temperatures without intention.
- Overuse bright accent colors.

## Avoid Poor Composition

Never:

- Fill every empty space.
- Place elements without alignment.
- Create accidental collisions.
- Ignore visual hierarchy.
- Use decorative shapes without purpose.
- Force symmetrical layouts unnecessarily.
- Make all elements equally prominent.

## Avoid Technical Shortcuts

Never:

- Replace the complete design with a flattened image.
- Use raster graphics when editable vector objects are required.
- Ignore font availability.
- Ignore document dimensions.
- Export without validation.
- Generate unsupported SVG features.

# 20. THE FINAL CREATIVE STANDARD

The goal is not to make every design look the same.

The goal is to make every design look appropriately and intentionally designed.

A luxury brochure should not look like a brutalist event poster.

An educational admission poster should not look like a restaurant advertisement.

A corporate business card should not look like an experimental magazine cover.

Each category requires its own creative intelligence, composition, typography, and visual language.

The platform must understand the difference.

## The Ultimate Standard

Every finished design should demonstrate:

- Creative intention.
- Professional art direction.
- Sophisticated composition.
- Typographic excellence.
- Intelligent color usage.
- Visual storytelling.
- Technical precision.
- Production quality.

**DO NOT GENERATE TEMPLATES. CREATE ORIGINAL GRAPHIC DESIGN COMPOSITIONS.**

**DO NOT DECORATE RANDOMLY. DESIGN WITH INTENTION.**

**DO NOT STOP AT RENDERING. CRITIQUE, REFINE, AND VALIDATE.**
